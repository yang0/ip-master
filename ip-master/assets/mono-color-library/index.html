Mono Color · 单色 / 受控双色编辑印刷

把主题、短句、物件、文章想法或照片，重建成原创编辑视觉。

GitHub ↗
怎么描述需求

直接说用途、主题、需要保留的文字或照片主体；没有额外指定时，Skill 会自行选择适合的油墨、版式和字体关系。明确说“单色 / 单墨”才使用单一油墨，否则默认受控双色。

可提供的输入主题、短句、物件、文章想法、授权照片。
可按需指定单色或双色墨色、标题、用途、横竖比例、是否保留照片身份。
核心规则最多两块印版；保留 25%–55% 可见纸张；默认当代编辑印刷，不自动做旧。
参考边界示例是输出案例，不是模板，也不会作为模型参考图传入。

最短调用示例

使用 mono-color-skill 做一张关于凌晨便利店的竖版海报，文案是“still open”。
使用 mono-color-skill 把这张人物照片做成钴蓝单色编辑 Zine 封面，保留人物身份和表情。
使用 mono-color-skill 用群青 + 安全橙做一张城市骑行叠印海报，让自行车与超大标题在局部交叉。
使用 mono-color-skill 把这个产品做成青蓝 + 砖红的重复物件封面，为标题和事实型小字保留一块空白区域。
