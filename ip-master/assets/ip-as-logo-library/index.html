它适合做什么

适合从一个动物、物件或已有角色概念出发，设计简单、可爱、适合长期复用的吉祥物形象。

视觉特征

4–7 个大形状、厚重圆润轮廓、两种角色主色加一种纯色背景、减少不必要细节。

怎么调用

默认会先提出 3 个设计方向，确认后再生成 6 张独立候选图。

使用 ip-as-logo 设计一个圆润可爱的猫咪 IP 吉祥物，主题：[品牌/产品主题]。

如果已有 IP，可直接写：使用 ip-as-logo 重新设计牙仔 IP，保持识别特征，做成极简圆润吉祥物。
