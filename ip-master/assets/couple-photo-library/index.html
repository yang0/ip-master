Couple Photo 情侣照工作流

从模糊想法开始，逐步确认情侣造型、场景、拍摄画面，再生成精修图。

先选择绝对项目目录。 这个工作流会在项目目录中保存需求、Look、Shot List、宫格和精修结果；不会默认复用当前目录或历史项目。

怎么使用

01 · 项目选择或新建一个空的绝对路径。
02 · 需求上传两张人物参考图，说主题、地点或想要的感觉。
03 · 确认确认 Couple Look，再确认 8 条拍摄画面。
04 · 出图生成 2×4 宫格，再选编号精修成横版或竖版。

官方 README 流程示例

可直接复制的最短用法

使用 couple-photo-orchestrator：我想拍一组情侣照。
使用 couple-photo-orchestrator：我想拍婚纱照。

它负责什么

  • 需求确认：把主题、服装、场景和道具整理成可确认的 Couple Look。
  • 拍摄规划：为每套 Look 生成 8 条有差异的 Shot List 和 2×4 宫格。
  • 换装候选：主题确认后生成 6 套情侣服装组合，用户选中后回流主流程。
  • 精修输出：用户选定宫格编号后，保留人物身份、互动和场景关系进行精修。
