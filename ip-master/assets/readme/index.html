设计新的 IP

上传照片、给账号或资料、或直接描述需求。下面是三种常用方向。

上传真人照片时，会先生成纯色背景高清四视图（脸部特写、正面、90°侧面、背面），再收集并确认姓名、年龄、身高、体重；确认后才进入项目角色库，四项资料也会写入图片。

人物 IP

根据照片、账号、资料或需求生成候选方向。

吉祥物 IP

根据品牌、产品或想法设计原创非人类角色。

个人卡通 IP

使用已授权的真人照片建立个人卡通形象。

项目角色库

确认后的自定义 IP 应保存到你的项目目录，不会写进 Skill 安装目录。项目根目录会生成可双击打开的 index.html，仅展示该项目的角色并可复制调用。

初始化 IP 项目：E:\projects\品牌IP

注册完成后可说：项目：E:\projects\品牌IP；使用 IP：项目角色名，制作一张海报，主题：新品发布。 内置角色依旧可直接使用，但不会出现在项目图册里。
